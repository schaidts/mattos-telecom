# Brasil Football Career 3.0

Abra `Brasil_Football_Career_3.0.html` no navegador (arquivo único, funciona offline e no celular).

- `src/` contém o código-fonte organizado por módulo (núcleo/dados, sprites, estádio, partida, interface).
- `python3 build.py` remonta o HTML final a partir de `src/`.
- `Brasil_Football_Career_2.0.html` é a versão anterior, mantida como referência.
- O save continua na chave `bfc2` do `localStorage`: carreiras da 2.0 continuam funcionando.
